# Quickstart: проверка следующей серии и ключей mpv

## Подготовка

Из корня проекта установить существующие зависимости и запустить проверки:

```bash
uv sync
uv run python -m unittest discover -s tests -v
```

Для ручной проверки нужны реальные видео 02 и 03 в одной папке; рядом могут быть подпапки нескольких студий и вариантов субтитров. Запустить окно:

```bash
uv run python media_picker.py
```

## Сценарии

1. Выбрать видео 02, аудио из `AniStar` и субтитры из `Crunchyroll`; добавить в те же подпапки дорожки для 03 и альтернативные варианты в другие подпапки. Нажать «Следующая серия». Ожидание: выбраны видео 03 и дорожки тех же источников, в окне показаны их пути, mpv запускает 03.
2. Выбрать видео 02, аудио и субтитры как выше; вручную выбрать видео 03. Ожидание: те же источники переносятся, mpv не запускается. Повторить с галочками автоподбора и связи панелей в обоих положениях и в режимах «Папки» и «Поиск».
3. Убрать дорожку 03 из выбранного источника и нажать кнопку. Ожидание: видео 03 выбрано, показан отсутствующий источник, mpv не запущен. Добавить второй похожий файл в ту же подпапку: выбор также требует ручного разрешения.
4. Проверить папку с видео 02 и 04 без 03, пару `S4 - 02 [1080p]` / `S4 - 03 [1080p]` и посторонний `12-audio.webm` между выпусками 11 и 12. Ожидание: пропущенный номер не перескакивается, сезон и разрешение не путаются с серией, посторонний файл пропускается.
5. При выключенном автоподборе снять выбор аудио и субтитров и нажать кнопку на выпуске 02. При пустом поле ключей ожидание: видео 03 запускается без внешних файлов.

Подробные правила выбора описаны в [контракте окна](contracts/ui.md) и [модели состояния](data-model.md).

## Дополнительные проверки ключей после реализации

Предварительно сохранить текущий текст поля, чтобы восстановить его после проверки. Для реального воспроизведения нужны установленный mpv и рабочая конфигурация; автоматические проверки используют временный INI и подменяют запуск, не требуют реальных медиа и не меняют настройки пользователя.

1. При отсутствии `options/mpv_arguments` поле пусто. Ввести `--fullscreen --sub-font="Noto Sans"`, закрыть приложение без запуска видео, открыть снова: текст должен совпасть посимвольно. Очистить поле, перезапустить: оно остаётся пустым.
2. Ввести `--volume=20 --volume=80 --sid=no`, выбрать видео и субтитры; запустить через «Смотреть», затем следующую серию. В обоих случаях субтитры отключены; автоматическая проверка должна подтвердить точный порядок всех аргументов, выбранное видео после `--` и сохранение повторов.
3. Проверить одинарные/двойные кавычки, обратную косую черту и значения с пробелами по [контракту](contracts/ui.md). Ввести `--title='$HOME; echo example'`: mpv получает буквальный заголовок, команды не выполняются.
4. По очереди ввести незакрытые кавычки, завершающий обратный слеш вне кавычек, `--volume 80`, отдельный путь, `-`, `--`, `--{`, `--}` и `""`. Оба действия должны показывать ошибку и не создавать процесс. Текст не очищается; после перезапуска ошибочный текст также восстанавливается.
5. После ошибки при переходе исправить поле и нажать «Смотреть»: запускается уже выбранная новая серия. Удалить выбранный файл или оставить нерешённый источник: пользовательские ключи не должны обходить прежний запрет запуска.
6. Автоматически подтвердить сохранение сразу после изменения через новый объект `QSettings` на том же временном INI, включая ведущие/замыкающие пробелы, незавершённые кавычки и очистку. Обновлённые проверки старых сценариев ожидают видео в конце после `--`.

Выполнить тот же `uv run python -m unittest discover -s tests -v`; проверить внешний вид, подпись и клавиатурный доступ вручную. Этот документ описывает проверки будущей реализации, а не утверждает, что новое поле уже существует.
