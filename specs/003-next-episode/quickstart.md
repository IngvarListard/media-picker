# Quickstart: проверка следующей серии

## Подготовка

Из корня проекта установить существующие зависимости и запустить проверки:

```bash
uv sync
uv run python -m unittest discover -s tests -v
```

Для ручной проверки нужны реальные видео 02 и 03 в одной папке; рядом могут быть подпапки нескольких студий и вариантов субтитров. Запустить окно:

```bash
uv run python media_picker.py
```

## Сценарии

1. Выбрать видео 02, аудио из `AniStar` и субтитры из `Crunchyroll`; добавить в те же подпапки дорожки для 03 и альтернативные варианты в другие подпапки. Нажать «Следующая серия». Ожидание: выбраны видео 03 и дорожки тех же источников, в окне показаны их пути, mpv запускает 03.
2. Выбрать видео 02, аудио и субтитры как выше; вручную выбрать видео 03. Ожидание: те же источники переносятся, mpv не запускается. Повторить с галочками автоподбора и связи панелей в обоих положениях и в режимах «Папки» и «Поиск».
3. Убрать дорожку 03 из выбранного источника и нажать кнопку. Ожидание: видео 03 выбрано, показан отсутствующий источник, mpv не запущен. Добавить второй похожий файл в ту же подпапку: выбор также требует ручного разрешения.
4. Проверить папку с видео 02 и 04 без 03, пару `S4 - 02 [1080p]` / `S4 - 03 [1080p]` и посторонний `12-audio.webm` между выпусками 11 и 12. Ожидание: пропущенный номер не перескакивается, сезон и разрешение не путаются с серией, посторонний файл пропускается.
5. При выключенном автоподборе снять выбор аудио и субтитров и нажать кнопку на выпуске 02. Ожидание: видео 03 запускается без внешних файлов.

Подробные правила выбора описаны в [контракте окна](contracts/ui.md) и [модели состояния](data-model.md).
