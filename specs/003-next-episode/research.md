# Research: следующая серия и ключи mpv

## Решения

| Решение | Обоснование | Рассмотренная альтернатива |
|---|---|---|
| Просматривать последующие видео уже показанного списка и переходить при единственном файле, где нечисловые фрагменты совпадают, а ровно одно число выросло на `1`. | Пропускает посторонний `audio.webm` между выпусками 11 и 12, но не перескакивает отсутствующий номер. Несколько подходящих файлов считаются неоднозначностью. | Проверять только соседнюю строку: реальный посторонний файл прерывает переход. Брать последний номер имени: путает разрешение с серией. |
| Помнить для аудио и субтитров источник отдельно от выбранного пути: относительную подпапку под папкой прежнего видео или абсолютную папку вне неё. | Источник сохраняется при переходе по папкам видео, когда выбранный путь временно очищается. | Держать старый путь выбранным: показывает файл прежней серии и создаёт риск запуска с ним. |
| В целевой папке источника применить существующее `matching(new_video, ...)` и выбрать файл только при одном результате. | Одинаково работает для папок и поиска, даже если в других подпапках есть варианты; неоднозначность видна пользователю. | Брать первый результат или запускать полный рекурсивный поиск при каждой смене серии: неверный выбор или лишняя задержка. |
| Хранить источники независимо от выбранного видео, затем при смене видео обновлять панели и пути. | Источник хранится отдельно в `sources`, поэтому очистка выбранного пути не теряет базу переноса. `fill()` уже блокирует сигналы списка. | Выводить старое состояние из нового выбора после сигнала: прежнего пути уже нет. |
| В режиме «Папки» открыть папку перенесённой дорожки; в режиме поиска оставить переключатель и показать выбранный полный путь. | Выбранный файл виден в папочном списке, а режим пользователя не переключается. | Автоматически включать поиск: неожиданно меняет режим панели. |
| Кнопка использует общую проверку файлов и запуск `launch()`; при отсутствующем или неоднозначном прежнем источнике выбирает видео, показывает причину и не вызывает запуск. | Не дублирует сбор аргументов mpv и сохраняет явный запрет на неверную дорожку. | Автоматически заменить источник другим или запустить без него: противоречит принятому сценарию. |

## Интеграционные замечания

- `scan_tracks()` уже держит снимок для одной папки видео; при переходе внутри неё повторный рекурсивный обход не нужен. Папку известного источника можно читать напрямую для актуальной проверки файла.
- `video_changed()` очищает старые пути, сначала ищет дорожки в `sources`, а общий автоподбор применяет только при отсутствии прежнего источника. Этот существующий порядок сохраняется.
- `fill()` очищает статус панели, поэтому сообщение об отсутствующем источнике следует показывать после обновления списка либо хранить в состоянии панели.
- `launch()` уже проверяет существование файлов и передаёт их в `subprocess.Popen` отдельными аргументами.

## Дополнение 2026-10-05: пользовательские ключи mpv

| Decision | Rationale | Alternatives considered |
|---|---|---|
| Использовать `shlex.split(text, comments=False, posix=True)` в небольшой чистой функции в `media_picker.py`. | Стандартная библиотека разбирает пробелы, кавычки и экранирование, сохраняет порядок/повторы. Пустая строка даёт `[]`; незакрытые кавычки и незавершённое экранирование дают `ValueError`. | `str.split()` ломает значения с пробелами; собственный парсер и дополнительные зависимости не нужны. |
| Проверять только формат: аргумент начинается с `-`, но не равен `-`, `--`, `--{`, `--}`. | Поле содержит опции, а не дополнительные позиционные файлы или маркеры области действия. Неизвестные названия опций проверяет установленный mpv. | Собственный каталог допустимых опций устаревает; полная командная строка с файлами меняет область функции. |
| Сохранить точный текст в `options/mpv_arguments` через существующие `QSettings`; записывать и вызывать `sync()` на `textChanged`. | Запуск не нужен для сохранения; очистка и незавершённый ввод восстанавливаются. Загрузка до подключения сигнала избегает лишнего сохранения. `status()` после синхронизации обнаруживает ошибку записи. | Сохранять только после успешного запуска теряет правки; новый файл настроек и отдельная кнопка сохранения дублируют Qt. |
| Общий `launch()` передаёт выбранные дорожки, затем пользовательские ключи, затем `--` и выбранное видео. | Все обычные опции действуют независимо от позиции видео. Собственный разделитель защищает позиционный аргумент. Последовательность пользовательских действий над списками и приоритет скалярных повторов не меняются. | Сортировка/удаление повторов меняет смысл; вставка ключей после `--` превращает их в имена файлов; отдельный запуск для следующей серии дублирует проверки. |
| Проверять новую логику в существующем `tests/test_ui.py` через временный INI и подмену `Popen`. | Проверяется реальный общий путь для обоих действий, сохранение без воспроизведения и запрет запуска при ошибке. | Новый фреймворк, отдельные тестовые модули и реальные процессы mpv для каждой проверки избыточны. |

### Проверенные источники и ограничения

- [Python: shlex](https://docs.python.org/3/library/shlex.html) описывает POSIX-режим разделения и обработку кавычек; это ограниченный разбор аргументов, не полная оболочка. Комментарии отключены, подстановка переменных, glob, команд и исполнение операторов не выполняются. Вложенный синтаксис фильтров mpv должен пережить этот внешний разбор. Исследователь проверил кавычки, пробелы, повторы, буквальные переменные и ошибки синтаксиса локально на Python.
- [Qt: QSettings](https://doc.qt.io/qt-6/qsettings.html) откладывает запись; `sync()` записывает ожидающие изменения, после чего `status()` показывает ошибку. Ошибка сохранения должна отображаться немодально, текст остаётся в поле. `status()` хранит первую ошибку объекта: не обещать автоматический сброс ошибки при исправлении прав. Хранилище, пути и идентификаторы приложения остаются существующими.
- [mpv: Usage](https://mpv.io/manual/stable/#usage): значение опции задаётся через `=`, `--` завершает опции. [Per-File Options](https://mpv.io/manual/stable/#per-file-options) подтверждает обычную глобальную область действия и специальные маркеры. [List Options](https://mpv.io/manual/stable/#list-options), [Audio](https://mpv.io/manual/stable/#audio) и [Subtitles](https://mpv.io/manual/stable/#subtitles) описывают изменение списков и добавление внешних файлов. Нельзя универсально трактовать любой повтор как замену значения.
- В ходе уточнения установленный mpv 0.41.0 проверен с `--no-config`, `--vo=null`, `--ao=null`, одним кадром `av://lavfi:testsrc` и `--term-playing-msg='VOLUME=${volume}'`: `--volume=10 --volume=20` дал 20, `--volume=20` перед источником и `--volume=10` после него дали 10. Эти проверки не загружали пользовательскую конфигурацию.

Все технические вопросы разрешены. Собственный перечень опций, управление процессом после запуска и получение итоговых выбранных mpv дорожек не требуются спецификацией.
