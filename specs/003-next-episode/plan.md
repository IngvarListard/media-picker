# Implementation Plan: следующая серия

**Branch**: `master` (active feature `003-next-episode`) | **Date**: 2026-10-02 | **Spec**: [spec.md](spec.md)

## Summary

Добавить кнопку «Следующая серия» к существующему окну. Она ищет единственный файл с номером `+1` среди последующих видео в естественно отсортированном списке, пропуская посторонние файлы, переносит выбранные источники аудио и субтитров и запускает mpv только при однозначном выборе всех ранее выбранных дорожек. Ручная смена видео использует тот же перенос без запуска. При отсутствии внешних дорожек запускается только видео.

## Technical Context

**Language/Version**: Python 3.12+  
**Primary Dependencies**: существующий PySide6; новых зависимостей нет  
**Storage**: состояние выбора в окне; существующие QSettings для папок и галочек, без новых настроек  
**Testing**: unittest для сравнения имён и переноса; offscreen Qt с подменой запуска mpv; ручная проверка окна  
**Target Platform**: Linux / KDE  
**Project Type**: локальное desktop-приложение  
**Performance Goals**: смена серии в текущей папке без повторного полного обхода дерева; сохраняется цель до 1 секунды на дереве из 500 файлов  
**Constraints**: ровно один подходящий видеофайл с одним числом `+1`; файлы из прежнего источника не подставляются произвольно; запуск через список аргументов subprocess  
**Scale/Scope**: один текущий видеофайл, до двух внешних дорожек, один снимок дерева поиска; без нового индексатора

## Constitution Check

*До Phase 0 и после Phase 1: пройдено.*

| Принцип | Решение |
|---|---|
| Минимальная реализация | Расширить `files.py` и `media_picker.py`; не добавлять слой, библиотеку или настройки. |
| Чистая работа с файлами | Сравнение имён и поиск соответствующей дорожки оставить вне Qt. |
| Переиспользование | Использовать `natural_key`, `matching`, `list_directory`, PySide6 и стандартную библиотеку. |
| Отзывчивость | Проверять уже показанный список видео и папки известных источников; сохранённый снимок поиска не пересканировать при каждом выборе серии. |
| Безопасный запуск | Показывать выбранные пути, проверять существование файлов и использовать текущий `subprocess.Popen` со списком аргументов. |

Нарушений принципов нет.
