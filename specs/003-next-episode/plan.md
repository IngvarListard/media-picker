# Implementation Plan: следующая серия и ключи mpv

**Branch**: `003-next-episode` | **Date**: 2026-10-05 | **Spec**: [spec.md](spec.md)

## Summary

Добавить кнопку «Следующая серия» к существующему окну. Она ищет единственный файл с номером `+1` среди последующих видео в естественно отсортированном списке, пропуская посторонние файлы, переносит выбранные источники аудио и субтитров и запускает mpv только при однозначном выборе всех ранее выбранных дорожек. Ручная смена видео использует тот же перенос без запуска. При пустом поле ключей и отсутствии внешних дорожек запускается только видео.

Переход и перенос источников уже реализованы. Текущее дополнение (FR-009–FR-014): добавить подписанный `QLineEdit` «Ключи mpv», сохранять точный текст в существующих `QSettings`, разбирать его через `shlex.split(..., comments=False, posix=True)` и проверять формат в общем `launch()`. Порядок команды: `mpv`, выбранные внешние дорожки, пользовательские ключи, `--`, видео. Правила неизвестных опций и списочных повторов остаются за mpv.

## Technical Context

**Language/Version**: Python 3.12+\
**Primary Dependencies**: существующий PySide6; новых зависимостей нет\
**Storage**: состояние выбора в окне; существующие QSettings для папок и галочек; один новый строковый ключ `options/mpv_arguments`, по умолчанию пустой\
**Testing**: unittest для сравнения имён и переноса; offscreen Qt с подменой запуска mpv; проверки аргументов, ошибок и сохранения в существующем `tests/test_ui.py`; ручная проверка окна\
**Target Platform**: Linux / KDE\
**Project Type**: локальное desktop-приложение\
**Performance Goals**: смена серии в текущей папке без повторного полного обхода дерева; сохраняется цель до 1 секунды на дереве из 500 файлов\
**Constraints**: ровно один подходящий видеофайл с одним числом `+1`; файлы из прежнего источника не подставляются произвольно; запуск через список аргументов subprocess; сохранение порядка и повторов опций, без оболочки и собственной базы опций mpv\
**Scale/Scope**: один текущий видеофайл, до двух внешних дорожек, один снимок дерева поиска; без нового индексатора

## Изменения для ключей mpv

1. В `MediaPicker.__init__` добавить над кнопками подписанное однострочное поле с примером `--fullscreen --sub-font="Noto Sans"`, доступным именем и клавиатурным фокусом. Восстановить `options/mpv_arguments` до подключения сохранения. Не нормализовать и не обрезать текст.
2. При `textChanged` записывать текст через `setValue` и `sync`, включая пустой и временно некорректный. При `QSettings.status() != NoError` показать понятную немодальную ошибку сохранения, оставить текст в поле; требование восстановления проверять на доступном для записи хранилище.
3. В чистой функции разобрать текст через `shlex.split(text, comments=False, posix=True)`. Разрешить только непустые токены с начальным `-`, исключая `-`, `--`, `--{`, `--}`. Никакой сортировки, удаления повторов, раскрытия переменных или шаблонов. Не проверять собственным списком названия опций mpv.
4. В `launch()` сохранить существующие проверки выбранного видео, источников и файлов. Перехватить `ValueError` разбора, показать русское сообщение и вернуть управление без `Popen`. Собрать список аргументов в порядке FR-014 и оставить `start_new_session=True` и существующую обработку `OSError`. `next_episode()` продолжает вызывать тот же `launch()` после переноса; при ошибке ключей уже выбранная новая серия остаётся в окне для исправления и запуска через «Смотреть».
5. В `tests/test_ui.py` обновить ожидания прежних команд под `--` и видео в конце; добавить компактные проверки обоих действий, кавычек/экранирования, повторов, запрещённых токенов, первого запуска и сохранения точного текста/очистки/некорректного текста без воспроизведения. Использовать существующие `unittest`, временный INI и подмену `Popen`/сообщений. После реализации выполнить проверки и ручные сценарии [quickstart.md](quickstart.md).

**Повторная проверка конституции после проектирования**: пройдена; новые сканирования файлов, зависимости и слои не вводятся. Неизвестных технических решений нет. Реализация и обновление `tasks.md` выполняются отдельными командами.
