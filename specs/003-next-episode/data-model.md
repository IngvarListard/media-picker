# Data model: следующая серия

Состояние остаётся внутри существующего `MediaPicker`; для ключей mpv используется существующее хранилище `QSettings` с одним новым строковым значением.

| Сущность | Данные | Правило |
|---|---|---|
| Текущее видео | `Path | None` | Выбранный файл в панели видео; полный путь сохраняется в `selection/video`, отсутствие выбора — пустая строка. При старте восстанавливается только файл из списка сохранённой папки без запуска mpv. Следующая серия берётся только из той же папки: среди последующих строк списка должен быть ровно один файл с номером `+1`. |
| Выбранная дорожка | По одному `Path | None` для аудио и субтитров | Перед сменой видео старый путь убирается; новый путь допустим только при однозначном соответствии. `None` означает отсутствие внешней дорожки. |
| Источник дорожки | Относительная папка внутри папки прежнего видео либо абсолютная внешняя папка | Запоминается отдельно от выбранного файла на время навигации по видео. Ручной выбор дорожки обновляет источник; выбор «Без внешней дорожки» очищает его. |
| Состояние панели | Режим «Папки / Поиск», текущая папка, список, статус | Режим сохраняется. В режиме «Папки» после переноса открывается папка выбранного файла. |
| Результат переноса | Выбран / отсутствует / неоднозначен, отдельно для каждой дорожки | Отсутствие или неоднозначность ранее выбранного источника запрещает автоматический запуск и требует видимого сообщения. |

| Текст ключей mpv | Строка `options/mpv_arguments`, по умолчанию `""` | Общая для всех видео; точный текст, включая пробелы, кавычки и временно некорректный ввод, сохраняется при каждом изменении. |
| Аргументы mpv | Временный `list[str]` | Производный результат `shlex.split(text, comments=False, posix=True)`; не хранится отдельно, порядок и повторы сохраняются. Формат описан в [контракте](contracts/ui.md). |

## Переходы

1. **Ручной выбор видео**: запомнить прежние источники, выбрать новое видео, очистить старые пути, найти по одному соответствующему файлу в каждом источнике, обновить панели. Воспроизведение не запускается.
2. **«Следующая серия»**: просмотреть последующие файлы списка, пропустить посторонние и найти единственный выпуск `+1`. Если его нет либо кандидатов несколько — оставить состояние и показать сообщение. Иначе выполнить тот же перенос; при успешном переносе запустить mpv. Если после обновления внешних дорожек нет, не добавлять опции дорожек от панелей; пользовательские ключи применяются в любом случае.
3. **Нет дорожки прежнего источника**: оставить новое видео выбранным, очистить путь проблемной дорожки, показать её источник, не запускать mpv до ручного исправления.
4. **Навигация по папкам видео**: выбранное видео может стать пустым, но сведения о ранее выбранных источниках сохраняются для следующего ручного выбора видео.

5. **Изменение ключей**: обновить точный текст, сохранить и синхронизировать настройки независимо от наличия видео и правильности синтаксиса. Ошибка сохранения видна пользователю; поле не очищается.
6. **Запуск**: проверенное текущее состояние файлов + разобранные ключи формируют один список аргументов. Ошибка разбора запрещает запуск и оставляет текст для исправления. При переходе новая серия может быть уже выбрана; ошибка ключей не возвращает старое видео.
7. **Новая сессия**: восстановить точный текст или пустую строку при отсутствии настройки. Очистка поля сохраняет пустую строку, а не возвращает прежние ключи.
