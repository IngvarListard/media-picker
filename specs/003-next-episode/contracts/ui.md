# UI contract: следующая серия

| Действие | Выбор в окне | Воспроизведение |
|---|---|---|
| Нажать «Следующая серия» при выбранном видео и единственном последующем выпуске `+1` | Пропустить посторонние файлы, выбрать новый видеофайл и однозначные дорожки прежних источников | Запустить mpv с показанными путями и текущими ключами |
| Нажать кнопку при выпусках 02 и 04 либо неоднозначном номере | Оставить прежний выбор, показать причину | Не запускать |
| Нажать кнопку без выбранных внешних дорожек при выключенном автоподборе | Выбрать следующую серию | Передать видео без опций дорожек от панелей, применить текущие ключи |
| Нажать кнопку, когда прежний источник отсутствует или неоднозначен | Выбрать новое видео, очистить проблемную дорожку, показать источник | Не запускать до ручного исправления |
| Вручную выбрать другое видео | Перенести дорожки из прежних источников; при сбое показать проблему | Не запускать |
| Перенести дорожку в режиме «Папки» | Открыть папку дорожки и выделить файл, даже при включённой связи панелей | По правилу действия выше |

- «Следующая серия» доступна при выбранном видео независимо от выбора аудио и субтитров.
- Галочка автоподбора не заменяет ранее выбранный источник другим. Если прежнего источника нет, действует существующий автоподбор единственного совпадения.
- Переключатели «Папки / Поиск» и «Панели следуют за видео» не меняют состояние при переносе.
- Полные пути выбранных файлов остаются видимы до запуска.

## Поле «Ключи mpv» (FR-009–FR-014)

- Подписанное однострочное поле над кнопками запуска, доступное с клавиатуры; пример: `--fullscreen --sub-font="Noto Sans"`.
- Точный текст сохраняется при изменении, включая очистку и незавершённый ввод, без запуска видео. При следующей сессии восстанавливается текст; отсутствующая настройка даёт пустое поле. Ошибка записи настройки сообщается пользователю, текст остаётся в поле.
- Изменение поля ничего не запускает. «Смотреть» и «Следующая серия» используют одни и те же правила разбора и запуска. Ручной выбор видео не запускает mpv.

### Формат и разбор

Разделение выполняется `shlex.split(text, comments=False, posix=True)`: пробелы вне кавычек разделяют аргументы; одинарные/двойные кавычки объединяют значение, поддерживается обратная косая черта. Комментарии отключены. Это разбор аргументов без исполнения оболочки: `$HOME`, `*` и текст команд внутри значений не раскрываются. Вложенные кавычки для фильтров mpv должны пережить внешний разбор, например внешние одинарные кавычки сохраняют внутренние двойные.

После разбора каждый токен должен начинаться с `-`, но не быть `-`, `--`, `--{` или `--}`. Пустой токен из `""` запрещён; пустой ввод или одни пробелы дают ноль аргументов. Для опции со значением требуется `=`, например `--volume=80`, а не `--volume 80`. Самостоятельные пути, команды и токены перенаправления отклоняются. Названия обычных опций и допустимость их значений проверяет mpv.

| Текст поля | Результат |
|---|---|
| `--fullscreen --sub-font="Noto Sans"` | Два аргумента: `--fullscreen`, `--sub-font=Noto Sans` |
| `--title='Серия 03'` | Один аргумент: `--title=Серия 03` |
| `--volume=20 --volume=80 --sid=no` | Три аргумента в исходном порядке; повторы остаются |
| `--sub-file="extra signs.ass"` | Дополнительный файл; семантику добавления определяет mpv |
| `--title='$HOME; echo example'` | Одно буквальное значение, без исполнения или подстановки |
| `--title="unfinished` или завершающий обратный слеш вне кавычек | Ошибка синтаксиса, процесс не создаётся |
| `--volume 80`, `extra.mkv`, `-`, `--`, `--{`, `--}`, `""` | Ошибка формата, процесс не создаётся |

Ошибка ключей показывается понятным русским сообщением; текст сохраняется. При нажатии «Следующая серия» новая серия может быть уже выбрана: после исправления ключей её можно запустить через «Смотреть». Отсутствие выбранных файлов или нерешённый источник дорожки продолжает блокировать запуск даже при пользовательских ключах.

### Граница запуска mpv

Аргументы передаются непосредственно в `subprocess.Popen`, без оболочки:

```text
["mpv", "--audio-file=<выбранное аудио>", "--sub-file=<выбранные субтитры>",
 <пользовательские аргументы в исходном порядке>, "--", "<выбранное видео>"]
```

Не выбранные в панелях дорожки не добавляют аргументы. Пользовательские ключи могут изменить выбор/отображение дорожек; панель продолжает показывать выбранный файл, а не вычислять итоговое состояние mpv. Повторные `--audio-file`/`--sub-file` добавляют файлы, поэтому перестановка аргументов не заменяет проверку правил mpv. Ошибки открытия исполняемого файла показываются существующей обработкой `OSError`; ошибки названий и значений опций остаются за mpv.
