## Phase 3: User Story 1 — Перейти к следующей серии (P1) 🎯 MVP

**Goal**: кнопка выбирает строго следующую серию, переносит выбранные дорожки и запускает mpv только при готовом выборе.

**Independent Test**: при видео 02 и 03 с дорожками из выбранных подпапок одно нажатие выбирает 03 и запускает mpv с путями 03; при пропуске 03 выбор не меняется; при отсутствии прежнего источника 03 выбирается без запуска.

- [X] T004 [P] [US1] Добавить в `tests/test_ui.py` проверку кнопки: аргументы `subprocess.Popen` для 03 с дорожками, запуск одного видео без дорожек, отсутствие запуска при пропуске серии, пропавшем или неоднозначном прежнем источнике.

## Implementation Strategy

Сначала закончить US1 как минимально полезную кнопку и проверить её независимо. Затем использовать уже готовый перенос для ручного переключения US2. После этого пройти quickstart и обновить README. Новые зависимости, настройки и отдельные архитектурные слои не нужны.
