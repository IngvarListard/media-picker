# Data model: файловый браузер

## Панель

- `kind`: video, audio или subtitle.
- `directory`: текущая существующая папка; папки каждой панели сохраняются независимо.
- `selected_file`: путь к выбранному файлу или отсутствие выбора.
- Список содержит `..` (кроме корня), подпапки и файлы разрешённого типа. Папки видны независимо от расширений.

## Настройки

- `last_directory` для каждой панели: последний открытый путь; первый запуск — `~/Downloads`, затем домашняя папка при его отсутствии.
- `follow_video`: включено по умолчанию; при выборе видео переводит панели дорожек в папку видео.
- `auto_select`: выключено по умолчанию; для каждой панели дорожки ищет единственное совпадение в её текущей папке.
- `extensions`: настраиваемые списки расширений видео, аудио и субтитров; значения по умолчанию берутся из files.py.
- Настройки сохраняются в `~/.config/MediaPicker/MediaPicker.ini`: `paths/video`, `paths/audio`, `paths/subtitle`, `options/follow_video`, `options/auto_select`, `extensions/video`, `extensions/audio`, `extensions/subtitle`. Расширения записываются строкой через запятую, например `.mkv,.mp4`.

## Выбор просмотра

- Обязателен один доступный видеофайл.
- Аудио и субтитры необязательны, максимум по одному файлу каждого вида.
- При смене видео оба внешних файла сбрасываются до необязательного автоподбора.
- При смене папки панели её выбранный файл сбрасывается. Перед запуском выбранные пути проверяются повторно.
