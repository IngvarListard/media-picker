# Research: файловый браузер

## Решения

- **Панели**: оставить уже используемый QListWidget. В каждой панели показывать строку `..`, каталоги и файлы разрешённых расширений из текущей папки. Одинарный клик по файлу выбирает его; двойной клик по папке открывает её. Это требует меньше изменений, чем новая модель дерева.
- **Настройки**: QSettings в формате INI хранит три текущие папки, состояние связи, автоподбора и списки расширений в `~/.config/MediaPicker/MediaPicker.ini`. Путь подтверждён установленным PySide6 через `QSettings.fileName()`. При первом запуске все панели открывают `~/Downloads`; если папки нет — домашнюю папку. Расширения нормализовать к нижнему регистру с ведущей точкой.
- **Выбор**: смена видео очищает внешние файлы, затем при включённой связи переводит панели в папку видео. При включённом автоподборе выбирать файл в текущей папке только при единственном совпадении.
- **Запуск**: сохранить проверку существования файлов и subprocess.Popen со списком аргументов. Кнопка доступна сразу после выбора видео.
- **Название**: нейтральное `Media Picker`; обновить точку входа и README.

## Рассмотренные варианты

- QFileSystemModel с тремя деревьями: встроенная модель подходит для больших деревьев, но текущий сценарий требует явного `..` и одного уровня папки; существующие списки проще.
- Собственный JSON/TOML плюс отдельная запись настроек: дублирует готовый INI-механизм Qt.
- Рекурсивный обход в браузерах: относится к отдельному режиму поиска и замедлил бы обычную навигацию.
