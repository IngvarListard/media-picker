# Feature Specification: Файловый выбор для mpv

**Created**: 2026-10-02  
**Status**: Ready for implementation  
**Input**: Одно окно с тремя файловыми браузерами для любого локального видео, внешнего аудио и субтитров; название приложения не должно ограничивать его аниме.

## Clarifications

### Session 2026-10-02

- Q: Где начинать просмотр файлов? → A: С последней использованной папки; при первом запуске — с `~/Downloads`.
- Q: Как связать три браузера? → A: Связь настраивается; по умолчанию выбор видео переводит панели дорожек к нему, после чего они могут перемещаться независимо.
- Q: Когда доступен запуск? → A: При выбранном видео, даже без внешнего аудио и субтитров.
- Q: Какие файлы показывать в панелях дорожек? → A: Все файлы разрешённых типов в текущей папке; разрешённые расширения настраиваются в конфиге.
- Q: Какую папку открывают панели дорожек при выборе видео и включённой связи? → A: Папку выбранного видео; затем каждая панель перемещается самостоятельно.
- Q: Что делать с выбранными дорожками при смене видео? → A: По умолчанию снимать выбор; включаемая галочка выбирает единственный похожий файл в текущей папке или среди результатов поиска.

## User Scenarios & Testing

### User Story 1 - Смотреть видео с выбранными дорожками (Priority: P1)

Пользователь открывает приложение, просматривает произвольные папки в панели видео и выбирает файл. В двух соседних файловых браузерах он при необходимости выбирает внешнее аудио и субтитры, затем нажимает «Смотреть».

**Why this priority**: Видео можно открыть с нужными внешними файлами без ручной сборки команды.

**Independent Test**: Выбрать произвольное видео вне папки аниме и запустить его сначала без внешних файлов, затем с аудио и субтитрами.

**Acceptance Scenarios**:

1. **Given** выбрано видео, **When** пользователь просматривает папки дорожек, **Then** панели показывают папки и все файлы разрешённых типов в текущей папке.
2. **Given** выбраны видео, внешнее аудио и субтитры, **When** пользователь нажимает «Смотреть», **Then** проигрыватель получает ровно эти три файла.
3. **Given** внешние дорожки не выбраны, **When** пользователь запускает просмотр, **Then** mpv получает только видеофайл.
4. **Given** пользователь открыл вложенную папку в любой панели, **When** он выбирает `..`, **Then** панель возвращается в родительскую папку.

---

### User Story 2 - Ускорить повторный выбор (Priority: P2)

При повторном запуске пользователь возвращается в последние открытые папки. При выборе видео обе панели дорожек переходят в его папку, если не выключена связь. Галочка автоподбора может выбрать единственное совпадение в текущей папке.

**Why this priority**: Повторный выбор соседних видео и дорожек требует меньше действий.

**Independent Test**: Сохранить три разные папки, перезапустить приложение, затем проверить связь панелей и однозначный автоподбор.

**Acceptance Scenarios**:

1. **Given** открыты разные папки панелей, **When** пользователь перезапускает приложение, **Then** каждая панель возвращается в свою последнюю папку.
2. **Given** связь панелей с видео выключена, **When** пользователь выбирает другое видео, **Then** текущие папки аудио и субтитров не меняются.
3. **Given** включён автоподбор и в текущей папке ровно один похожий файл, **When** пользователь выбирает другое видео, **Then** этот файл выбирается; при нескольких совпадениях выбор остаётся пустым.
4. **Given** в конфиг добавлено расширение файла, **When** пользователь открывает содержащую его папку, **Then** файл отображается в соответствующей панели.

### Edge Cases

- Текущая папка не содержит разрешённых файлов: папки и переход `..` остаются доступны; запуск без выбранного видео недоступен.
- После отображения списка файл был удалён или переименован: приложение сообщает, какой выбранный файл недоступен, и не запускает ошибочную комбинацию.
- Файлы с одинаковыми именами в разных папках различаются по отображаемому пути.
- Имена содержат пробелы, скобки и кириллицу: выбирается и передаётся точный путь к файлу.
- Проигрыватель недоступен или не запускается: приложение сообщает об ошибке, сохраняя выбранные файлы для исправления.

## Requirements

### Functional Requirements

- **FR-001**: Приложение с нейтральным названием «Media Picker» MUST показывать в одном окне три панели выбора: видео, аудио и субтитры, а также действие «Смотреть».
- **FR-002**: Каждая панель MUST позволять открывать папки и переходить на уровень выше через `..`; папка коллекции не фиксирована.
- **FR-003**: Приложение MUST начинать с последней использованной папки, а при первом запуске — с `~/Downloads`.
- **FR-004**: По умолчанию выбор видео MUST переводить панели дорожек в папку выбранного видео; эту связь MUST быть возможно отключить. После перехода каждая панель перемещается независимо.
- **FR-005**: Приложение MUST показывать выбранные пути и источник дорожек перед запуском; варианты с одинаковыми именами из разных папок MUST различаться.
- **FR-006**: Каждая панель MUST показывать все файлы разрешённых для неё типов в текущей папке независимо от сходства имён с видео. Списки разрешённых расширений MUST задаваться в конфиге.
- **FR-007**: Приложение MUST запускать выбранное видео с выбранными внешними дорожками в mpv и MUST не запускать просмотр без выбранного доступного видео.
- **FR-008**: Приложение MUST сообщать о недоступных выбранных файлах и ошибке запуска проигрывателя так, чтобы пользователь мог исправить выбор.
- **FR-009**: Кнопка «Смотреть» MUST быть доступна при выборе видео независимо от выбора внешних дорожек.
- **FR-010**: При смене видео приложение MUST снимать выбор внешних дорожек. Общая для двух панелей выключенная по умолчанию галочка MUST выбирать дорожку в текущей папке, только если ровно один файл совпадает с именем видео без расширения без учёта регистра либо начинается с этого имени и точки; при нуле или нескольких совпадениях выбор остаётся пустым.

### Key Entities

- **Папка панели**: текущая папка одного из трёх браузеров.
- **Видео**: выбранный локальный видеофайл.
- **Дорожка**: внешний аудиофайл или файл субтитров, его путь и источник (например, студия или группа субтитров).
- **Выбор просмотра**: видео и ноль или один внешний аудиофайл и файл субтитров.

## Success Criteria

### Measurable Outcomes

- **SC-001**: Пользователь может запустить произвольное локальное видео без внешних дорожек и без размещения в специальной папке.
- **SC-002**: В каждой панели пользователь может открыть вложенную папку и вернуться через `..`.
- **SC-003**: Файлы разрешённых типов видны независимо от сходства имён с видео.
- **SC-005**: При включённом автоподборе из двух похожих файлов в текущей папке ни один не выбирается автоматически.
- **SC-004**: В проверке с отсутствующим, переименованным или вручную выбранным файлом пользователь видит точный выбор или понятную ошибку до запуска.

## Assumptions

- Приложение используется локально одним пользователем.
- Проигрыватель mpv установлен в системе.
- Папки панелей и пользовательские настройки сохраняются между запусками приложения.
