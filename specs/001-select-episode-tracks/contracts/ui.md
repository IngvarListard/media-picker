# UI contract: файловый браузер

| Элемент | Действие | Результат |
|---|---|---|
| Любая панель | Двойной клик по папке или `..` | Открыть папку и обновить строку текущего пути. |
| Любая панель | Клик по файлу разрешённого типа | Показать выбранный полный путь. |
| Видео | Выбор другого файла | Сбросить аудио и субтитры; при включённой связи открыть папку видео в их панелях; затем выполнить автоподбор, если включён. |
| Аудио/субтитры | Оставить без выбора | При запуске не передавать соответствующий внешний файл. |
| Связь панелей | Выключить | Выбор видео больше не меняет текущие папки дорожек. |
| Автоподбор | Включить | При выборе видео выбрать ровно одно совпадение в текущей папке каждой панели; при нуле или нескольких оставить пусто. |
| Смотреть | Нажать при выбранном видео | Проверить пути и открыть mpv с точной комбинацией файлов. |

- Кнопка «Смотреть» активна при выбранном видео независимо от внешних файлов.
- В каждой панели показываются папки и все файлы разрешённого типа, даже если имя не совпадает с видео.
- Настройки и текущие папки восстанавливаются после перезапуска.
- При недоступном файле или ошибке запуска окно показывает причину и сохраняет выбор для исправления.
- Название окна — Media Picker. Рекурсивного поиска в этом этапе нет.
