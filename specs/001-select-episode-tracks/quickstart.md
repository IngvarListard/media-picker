# Quickstart: проверка файлового браузера

## Подготовка

1. `uv sync`; убедиться, что `mpv` доступен.
2. Запустить `uv run python media_picker.py`.
3. Подготовить папку с видео и вложенными папками аудио/субтитров вне `~/Downloads/Anime`.

## Проверка

1. При первом запуске панели открывают `~/Downloads` (или домашнюю папку, если Downloads нет). Открыть произвольную папку и вернуться через `..` в каждой панели.
2. Выбрать видео: кнопка «Смотреть» активна без дорожек; mpv открывает один видеофайл.
3. В аудио и субтитрах открыть вложенные папки, выбрать файлы, проверить полные пути и запустить mpv с тремя файлами.
4. Проверить связь: по умолчанию выбор другого видео переводит панели дорожек в его папку; при выключенной связи оставляет текущие папки.
5. Включить автоподбор: при одном совпадении в текущей папке файл выбирается, при двух — выбор пустой.
6. Перезапустить приложение: папки, переключатели и списки расширений сохраняются. Добавить расширение в `~/.config/MediaPicker/MediaPicker.ini` и проверить, что файл появился в панели.
7. Удалить выбранный файл до запуска и проверить понятную ошибку. Проверить путь с пробелами и кириллицей.

Проверка файловых функций: `uv run python -m unittest discover -s tests`.
