# Implementation Plan: файловый браузер для mpv

**Branch**: `master` | **Date**: 2026-10-02 | **Spec**: [spec.md](spec.md)

## Summary

Заменить выбор тайтла и списки совпадений тремя настоящими браузерами папок. Сохранить простое окно PySide6: список папок и разрешённых файлов в каждой панели, строка текущего пути, переход `..`, выбор файла. При выборе видео панели дорожек по умолчанию переходят в его папку. Выбранное видео запускается через mpv с нулём, одним или двумя внешними файлами. Состояние папок, связь панелей, автоподбор и разрешённые расширения хранить в одном пользовательском конфиге.

## Technical Context

**Language/Version**: Python 3.12+  
**Primary Dependencies**: существующий PySide6, системный mpv  
**Storage**: `~/.config/MediaPicker/MediaPicker.ini` через Qt QSettings  
**Testing**: unittest для списка файлов и сопоставления; ручная проверка окна и запуска  
**Target Platform**: Linux / KDE  
**Project Type**: локальное desktop-приложение  
**Performance Goals**: папка до 500 элементов открывается без заметной задержки  
**Constraints**: три панели в одном окне, никакого фиксированного корня, передача аргументов mpv без shell  
**Scale/Scope**: один пользователь, одно выбранное видео, до двух внешних файлов; рекурсивный поиск вынесен в [спецификацию 002](../002-search-tracks/spec.md)

## Constitution Check

*До и после проектирования: пройдено.*

| Принцип | Решение |
|---|---|
| Минимальная реализация | Использовать существующий QListWidget и несколько небольших функций, без новых зависимостей. |
| Чистая работа с файлами | Фильтрация, сортировка и сопоставление в files.py; Qt и запуск процесса на краях. |
| Переиспользование платформы | QSettings для INI, pathlib для путей, subprocess.Popen для mpv. |
| Отзывчивость | Просматривать только открытую папку; рекурсивного обхода в этом этапе нет. |
| Безопасный запуск | Проверить файлы и передать список аргументов без shell. |
