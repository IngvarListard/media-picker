# UI contract: режим поиска

| Действие | Аудио | Субтитры |
|---|---|---|
| Включить «Поиск» в панели | Показать похожие аудиофайлы во всех подпапках видео | Показать похожие субтитры во всех подпапках видео |
| Выключить «Поиск» | Вернуться к сохранённой папке аудио | Вернуться к сохранённой папке субтитров |
| Выбрать новое видео | Обновить список согласно режиму аудио | Обновить список согласно режиму субтитров |
| Включить общий автоподбор | Выбрать единственный файл из активного списка, иначе оставить пусто | То же независимо для субтитров |

- Переключатель одной панели не меняет режим другой.
- При смене режима выбор этой дорожки очищается; при включённом автоподборе может появиться новый однозначный выбор.
- В поиске каждая строка различает путь относительно папки видео, даже если имена файлов одинаковы.
- Состояние `..` и текущая папка браузера сохраняются при временном переходе в поиск.
- Недоступные подпапки не прерывают поиск в доступных; ошибка понятна пользователю.
