# Quickstart: проверка поиска дорожек

## Подготовка

1. Завершить браузер из спецификации 001; выполнить `uv sync`.
2. В папке видео создать две вложенные папки аудио и одну папку субтитров. Разместить файлы с тем же именем без расширения, что у видео, и один файл с непохожим именем.
3. Запустить `uv run python media_picker.py`.

## Проверка

1. Выбрать видео; аудио переключить в «Поиск», субтитры оставить в «Папках». Аудио показывает файлы из вложенных папок с различимыми путями; субтитры продолжают навигацию.
2. Переключить субтитры в «Поиск»: показать подходящие файлы из вложенной папки. Непохожий файл отсутствует в результатах.
3. Включить автоподбор: при двух похожих аудиофайлах аудио не выбрано, при одном похожем субтитре он выбран. В режиме «Папки» та же галочка проверяет только текущую папку.
4. Выбрать другое видео в той же папке: результаты обновляются, старые дорожки не остаются выбранными.
5. Выключить поиск в одной панели: её прежняя папка доступна, другая панель остаётся в поиске.
6. Сделать одну подпапку недоступной: доступные результаты остаются, ошибка показана. На дереве из 500 файлов результаты появляются не позже 1 секунды.
7. Выбрать найденные аудио и субтитры и проверить фактический запуск mpv с точными путями.

Чистые функции: `uv run python -m unittest discover -s tests`.
