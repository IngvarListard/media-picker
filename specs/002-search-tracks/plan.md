# Implementation Plan: поиск внешних дорожек

**Branch**: `master` | **Date**: 2026-10-02 | **Spec**: [spec.md](spec.md)

## Summary

Добавить к готовому файловому браузеру независимый переключатель «Папки / Поиск» для аудио и субтитров. Поиск один раз собирает разрешённые дорожки из папки выбранного видео и всех подпапок; при выборе другого видео в той же папке фильтрует уже собранный список по точному имени либо суффиксу через точку. Результаты показываются с относительными путями. Общая галочка автоподбора выбирает файл лишь при единственном совпадении в активном режиме каждой панели.

## Technical Context

**Language/Version**: Python 3.12+  
**Primary Dependencies**: существующий PySide6; новых зависимостей нет  
**Storage**: текущее состояние режимов и снимок файлов в памяти окна; конфиг браузера остаётся общим  
**Testing**: unittest для рекурсивного поиска/сопоставления; ручная проверка независимых режимов  
**Target Platform**: Linux / KDE  
**Project Type**: локальное desktop-приложение  
**Performance Goals**: до 1 секунды для дерева из 500 файлов  
**Constraints**: область поиска — папка видео и подпапки; без обхода всего домашнего каталога; режимы двух панелей независимы  
**Scale/Scope**: одно выбранное видео, до двух внешних файлов, один текущий снимок дерева; зависит от завершения спецификации 001
