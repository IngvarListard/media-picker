# Feature Specification: Поиск внешних дорожек

**Feature Branch**: `master`  
**Created**: 2026-10-02  
**Status**: Ready for implementation after specification 001  
**Input**: Помимо обычного просмотра папок нужен режим поиска похожих на видео аудио и субтитров во всех подпапках папки видео.

## Clarifications

### Session 2026-10-02

- Q: Откуда искать дорожки? → A: В папке выбранного видео и всех её подпапках.
- Q: Что делать при нескольких совпадениях для автоматического выбора? → A: Не выбирать ни одного и показать все результаты.
- Q: Как переключать режимы двух колонок? → A: У аудио и субтитров собственные переключатели «Папки / Поиск».
- Q: Какие имена считать совпадением? → A: Одинаковое имя без расширения без учёта регистра либо имя видео с дополнительным суффиксом через точку.
- Q: В каких режимах работает автоматический выбор? → A: В обоих; в режиме «Папки» проверяется текущая папка, в режиме «Поиск» — все найденные результаты.

## User Scenarios & Testing

### User Story 1 - Найти внешние дорожки (Priority: P1)

Пользователь выбирает видео и включает режим поиска в нужной панели дорожки. Она показывает подходящие по имени файлы из всех подпапок папки видео. Каждый результат показывает путь, чтобы различать одинаковые имена из разных папок. Пользователь выбирает нужные файлы и запускает просмотр.

**Why this priority**: Аудио и субтитры чаще лежат в отдельных подпапках, и переходить в каждую вручную долго.

**Independent Test**: Разместить видео в папке, аудио и субтитры в разных вложенных папках, включить поиск и выбрать оба файла из результатов.

**Acceptance Scenarios**:

1. **Given** видео и похожие дорожки во вложенных папках, **When** пользователь включает поиск в панели дорожки, **Then** эта панель показывает все найденные совпадения с различимыми путями, а режим другой панели не меняется.
2. **Given** в подпапке есть файл разрешённого типа с непохожим именем, **When** пользователь смотрит результаты поиска, **Then** этот файл не показывается.
3. **Given** пользователь выключает поиск, **When** он открывает панель дорожки, **Then** панель снова позволяет ходить по папкам согласно базовой спецификации.

---

### User Story 2 - Автоматически выбрать однозначные дорожки (Priority: P2)

Галочка автоматического выбора из базовой спецификации работает и в режиме поиска. При смене видео приложение выбирает найденную дорожку, только если совпадение однозначно; остальные результаты остаются доступны для ручного выбора.

**Why this priority**: Следующее видео можно запускать быстрее без риска молча выбрать произвольную озвучку.

**Independent Test**: Последовательно проверить папки с одним, несколькими и нулём совпадений для каждого типа дорожек.

**Acceptance Scenarios**:

1. **Given** найден один похожий аудиофайл, **When** включён автоматический выбор, **Then** он выбран.
2. **Given** найдено несколько похожих файлов, **When** включён автоматический выбор, **Then** ни один не выбран, а все результаты видны.
3. **Given** автоматический выбор выключен, **When** пользователь выбирает другое видео, **Then** внешние дорожки остаются невыбранными.

### Edge Cases

- Если видео не выбрано, поиск не показывает результаты и не выбирает дорожки.
- Если папка видео не содержит совпадений, панели в режиме поиска показывают пустой результат без ошибки; можно вернуться к просмотру папок.
- Если два результата имеют одинаковое имя, их пути отображаются так, чтобы можно было выбрать нужный.
- При смене видео старые результаты и выбранные файлы не используются для нового видео.
- Папки без права чтения пропускаются с понятным сообщением, поиск доступных папок продолжается.

## Requirements

### Functional Requirements

- **FR-001**: Приложение MUST предоставлять режим просмотра папок из базовой спецификации и отдельный режим поиска дорожек.
- **FR-002**: Поиск MUST обходить папку выбранного видео и все её подпапки.
- **FR-003**: Панели аудио и субтитров MUST показывать все найденные файлы соответствующих разрешённых типов, чьё имя без расширения совпадает с именем видео без расширения без учёта регистра либо начинается с этого имени и точки; пути результатов MUST различаться.
- **FR-004**: При смене видео MUST обновляться результаты поиска, а выбор дорожек MUST сбрасываться до нового выбора или однозначного автоматического совпадения.
- **FR-005**: Каждая из двух панелей дорожек MUST независимо переключаться между просмотром папок и результатами поиска.
- **FR-006**: Галочка автоматического выбора из базовой спецификации MUST также работать в режиме поиска; среди всех найденных результатов файл MUST выбираться только при ровно одном совпадении.
- **FR-007**: Выбранные из результатов файлы MUST передаваться при запуске по правилам базовой спецификации.

### Key Entities

- **Область поиска**: папка выбранного видео вместе с вложенными папками.
- **Результат поиска**: тип файла, путь и совпадение с выбранным видео.
- **Режим панели**: просмотр папок или показ результатов поиска.

## Success Criteria

### Measurable Outcomes

- **SC-001**: Дорожки в двух уровнях вложенных папок доступны для выбора без ручного открытия этих папок.
- **SC-002**: Все подходящие дорожки из проверочного набора до 500 файлов появляются в соответствующих панелях в течение 1 секунды после выбора видео.
- **SC-003**: При нескольких совпадениях ни одна дорожка не выбрана автоматически.
- **SC-004**: После выключения поиска пользователь может снова открыть вложенную папку и вернуться через `..`.

## Assumptions

- Базовый файловый браузер описан в [спецификации 001](../001-select-episode-tracks/spec.md).
- При открытии приложения активен режим просмотра папок; поиск включается пользователем.
- Разрешённые расширения задаются общим конфигом из базовой спецификации.
