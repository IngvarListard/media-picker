## Phase 3: User Story 1 — Найти внешние дорожки (P1) 🎯 MVP

**Goal**: независимо включать поиск в аудио и субтитрах и выбирать результаты из подпапок.

**Independent Test**: поиск аудио показывает вложенные файлы, пока субтитры остаются в режиме просмотра папок; после переключения субтитры также находят свои файлы.

- [X] T004 [US1] Добавить в `media_picker.py` отдельный переключатель «Папки / Поиск» для аудио и субтитров; при смене режима очищать выбор этой панели и сохранять её текущую папку браузера.
- [X] T005 [US1] Добавить в `media_picker.py` один снимок разрешённых дорожек для папки выбранного видео: пересканировать при смене папки или включении поиска, при выборе другого видео в той же папке фильтровать снимок через существующее правило совпадения.
- [X] T006 [US1] Показать в поисковых списках `media_picker.py` все совпадения с путём относительно папки видео и полным путём выбранного файла; показать понятное сообщение о недоступных подпапках, не скрывая доступные результаты; переключение одной панели не меняет другую.

**Checkpoint**: ручной выбор дорожки из вложенной папки работает независимо в каждой панели.

## Implementation Strategy

Сначала завершить браузер, затем показать ручной поиск в одной панели без изменения другой. После этого подключить общую галочку автоподбора, измерить скорость и проверить реальные файлы в mpv.
