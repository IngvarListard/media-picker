# Data model: поиск дорожек

## Режим панели дорожки

- `mode`: folders или search, отдельно для аудио и субтитров.
- `directory`: папка браузера из спецификации 001; сохраняется при временном включении поиска.
- `selected_file`: выбранный внешний файл или отсутствие выбора; очищается при смене видео либо режима.

## Снимок дерева

- `root`: папка выбранного видео.
- `audio_files`, `subtitle_files`: пути разрешённых файлов во всех доступных подпапках.
- `read_errors`: недоступные подпапки для понятного сообщения.
- Снимок заменяется при смене root и новом включении поиска; внутри той же папки новое видео только повторно фильтрует списки.

## Результат

- Файл нужного типа, совпадающий с видео по правилу spec.md.
- Метка: путь относительно root; полный путь остаётся значением выбора.
- Автоподбор работает только при ровно одном результате в активном режиме панели.
