# Research: рекурсивный поиск дорожек

## Решения

- **Обход**: один проход по папке видео через стандартный os.walk без следования ссылкам на каталоги. Ошибки чтения отдельных подпапок собрать для сообщения, остальную часть дерева продолжить обходить.
- **Снимок**: хранить только аудио и субтитры текущей папки видео. При выборе другого видео в той же папке использовать этот список; при смене папки или новом включении поиска пересканировать. Это не постоянный кеш.
- **Совпадение**: использовать существующее правило files.matching: имя без расширения равно имени видео без расширения без учёта регистра либо начинается с имени видео и точки.
- **Независимые панели**: два переключателя меняют источник списка только своей панели; текущая папка браузера сохраняется при переходе в поиск и обратно. Смена режима очищает выбранную дорожку, затем при включённом автоподборе выбирает единственный результат активного режима.
- **Представление**: результаты показывать с путём относительно папки видео, полный путь оставлять в строке выбора и подсказке.
- **Отзывчивость**: сначала измерить синхронный обход 500 локальных файлов. Фоновый поток вводить только если проверка показывает задержку свыше 1 секунды.

## Рассмотренные варианты

- Обход всего домашнего каталога: выходит за пределы выбранного видео и создаёт лишние результаты.
- Выбор первого совпадения: может подставить не ту озвучку.
- Постоянный индекс/база данных: не нужен для одной текущей папки.
