# Контракт окна и меню

## Поведение окна при отсутствии mpv (FR-006, FR-007)

| Ситуация | Окно | Запуск |
|---|---|---|
| mpv не найден, окно только открыто | Обычное окно; короткое предупреждение в панели видео; остальные панели работают | — |
| mpv не найден, нажато «Смотреть» | Сообщение в отдельном окне с командами установки; выбор файлов не сбрасывается; приложение не закрывается | Не запускается |
| В настройках указан несуществующий путь | То же сообщение, что и при отсутствии mpv, без технических подробностей запуска процесса | Не запускается |
| mpv поставлен после запуска окна | Окно продолжает работать; сообщение больше не появляется | Запускается по повторному нажатию, без перезапуска приложения |

Правила существующего окна не меняются: при проблемах с выбранными дорожками кнопка «Смотреть» недоступна и сообщение показывается в панели — это отдельный случай и он имеет приоритет. Предупреждение об отсутствии mpv не блокирует кнопку, чтобы после установки mpv не требовался перезапуск.

## Настройки (FR-008, FR-009)

- Новый ключ `options/mpv_path` в существующем файле настроек; пустое значение — поиск в `PATH`. Поле в окне не добавляется.
- При первом запуске открывается папка загрузок, определённая системой, — в том числе при локализованном имени; если она недоступна, открывается домашняя папка. Поведение сохранённой папки и сохранённой серии не меняется.

## Меню приложений и значок (FR-010)

| Элемент | Значение |
|---|---|
| Имя файла записи | `io.github.IngvarListard.MediaPicker.desktop` |
| Название | Media Picker |
| Команда | `media-picker` |
| Значок | `io.github.IngvarListard.MediaPicker` |
| Тип | Application |
| Категории | AudioVideo;Player; |
| Терминал | не требуется |
| Аргументы | не принимает (путь к видео в этот этап не входит) |
| Установка | документированная команда копирования в пользовательские каталоги приложений и значков, без прав root |

- Значок окна задаётся приложением при запуске, поэтому он виден и при запуске из терминала, без записи в меню.
- Значок поставляется размером 256×256 в формате PNG.
- Метаинфо-файл `io.github.IngvarListard.MediaPicker.metainfo.xml` содержит название, краткое и полное описание, ссылку на репозиторий, лицензию и сведения о выпуске.

## Что остаётся без изменений (FR-014)

Панели и их режимы, автоподбор совпадения, «Следующая серия», поле ключей mpv, порядок аргументов запуска, хранение папок, галочек, серии и расширений — всё поведение прежних спек сохраняется. Файлы передаются процессу списком аргументов; имена из настроек в текст сообщений не подставляются.
