# Контракт команд: установка и запуск

## Установка

| Способ | Команда | Когда применим |
|---|---|---|
| Из публичного каталога | `uv tool install media-picker` | Основной путь после первой публикации. Ставит приложение для текущего пользователя, без прав root |
| Альтернатива из каталога | `pipx install media-picker` | Если у пользователя уже есть pipx |
| Напрямую из репозитория | `uvx --from git+ssh://git@github.com/IngvarListard/media-picker media-picker` | Пока пакет не опубликован; запуск без установки |
| Обновление | повтор любой команды установки с ключом замены | Заменяет предыдущую версию, настройки пользователя не трогает |

Требования: однократное подключение к сети, Python 3.12+ (либо установщик, который его поставит), система не старше Ubuntu 22.04 / Debian 12 / Fedora 35.

## Запуск

| Команда | Поведение |
|---|---|
| `media-picker` | Открывает окно из любого текущего каталога, независимо от наличия исходного кода рядом |
| `media-picker` при отсутствующем mpv | Окно открывается, предупреждение видно, запуск видео объясняет установку mpv |

Путь к видео аргументом командной строки в этом этапе не поддерживается.

## Сообщение об отсутствии mpv

Обязательные свойства (FR-006, FR-007):

- объясняет, что для просмотра нужен mpv, и что его ставит пользователь;
- перечисляет команды минимум для четырёх каналов: Debian/Ubuntu, Fedora, Arch, Flatpak;
- не содержит подстановок из настроек или имён файлов пользователя;
- не завершает приложение и не сбрасывает выбор файлов;
- после появления mpv в системе повторное нажатие «Смотреть» запускает видео без перезапуска приложения.

## Настройка пути к mpv

| Ключ | Формат | Значение по умолчанию | Поведение |
|---|---|---|---|
| `options/mpv_path` | Путь к исполняемому файлу | пустая строка | Пусто — поиск в `PATH`. Непустое значение — предпочтительный путь; если недоступен, поиск снова идёт по `PATH`, и только затем показывается сообщение об отсутствии |

Раздел настроек остаётся существующим: `~/.config/MediaPicker/MediaPicker.ini`, приложение `MediaPicker`, организация `MediaPicker`.

## Сборка пакета

| Свойство | Значение |
|---|---|
| Имя и точка входа | `media-picker`, команда `media-picker` |
| Объявленные модули | `media_picker`, `files` — плоские модули, файлы не переезжают |
| Рантайм-зависимости | только `pyside6-essentials` (графическая библиотека внутри пакета) |
| Артефакты | универсальное колесо — годится для любой архитектуры и любого дистрибутива не старше минимального |
