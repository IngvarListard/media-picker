# Data model: установка и запуск на любом Linux

Новых данных в приложении почти нет: состояние окна не меняется, добавляется один строковый ключ в существующий INI и несколько упаковочных сущностей, видимых системе.

| Сущность | Данные | Правило |
|---|---|---|
| Путь к mpv | Строка `options/mpv_path` в существующем INI, по умолчанию пустая | Пустая строка означает поиск в `PATH`. Непустая строка — предпочтительный путь; если он не существует или не является файлом, поиск откатывается к `PATH`, а затем к сообщению об отсутствии. Путь не проверяется на исполняемость: ошибку запуска сообщает существующая обработка сбоя процесса. |
| Найденный mpv | `str | None`, не хранится | Результат поиска: явный существующий путь, иначе первый найденный в `PATH`. Вычисляется при запуске действия, а не при построении списков. |
| Команда запуска | Временный `list[str]`, не хранится | Порядок: путь к mpv, выбранные внешние дорожки, пользовательские ключи, `--`, видео. Повторы и порядок пользовательских ключей сохраняются. |
| Папка загрузок | `Path`, не хранится | Берётся у системы; при недоступности — домашняя папка. Используется только как начальная папка первого запуска, как и раньше. |
| Установочный пакет | `pyproject.toml`: имя `media-picker`, версия, точка входа `media-picker`, зависимость `pyside6-essentials`, объявленные модули `media_picker` и `files` | Пакет ставится для текущего пользователя; повторная установка заменяет версию. Имя и точка входа совпадают, поэтому команда запуска одна и та же на любом дистрибутиве. |
| Запись в меню | Файл `io.github.IngvarListard.MediaPicker.desktop` | Ставится отдельной командой в пользовательский каталог приложений. Содержит имя, значок, команду запуска и признак отсутствия терминала; путь к видео не принимает. |
| Значок приложения | Файл `io.github.IngvarListard.MediaPicker.png`, 256×256 | Используется записью в меню и как значок окна при запуске из терминала. |
| Метаданные приложения | Файл `io.github.IngvarListard.MediaPicker.metainfo.xml` | Название, краткое и полное описание, ссылка на проект, сведения о версии и лицензии — то, что показывают меню и каталоги приложений. |
| Подсказка об отсутствии mpv | Текст, не хранится | Постоянный набор команд установки для Debian/Ubuntu, Fedora, Arch и Flatpak. Содержит только текст: ничего из настроек пользователя в него не подставляется. |

## Переходы

1. **Первый запуск после установки**: папка загрузок недоступна или не найдена → открывается домашняя папка. Никаких других изменений в поведении окна нет.
2. **Запуск видео при отсутствии mpv**: пользователь нажимает «Смотреть» → путь не найден → показывается подсказка с командами установки → выбор файлов сохраняется, приложение продолжает работу.
3. **Установка mpv после запуска приложения**: пользователь ставит mpv → нажимает «Смотреть» снова → путь находится заново → видео запускается без перезапуска приложения.
4. **Нестандартное расположение mpv**: пользователь вписывает путь в файл настроек → при запуске предпочитается этот путь → при его исчезновении поиск возвращается к `PATH`.
5. **Добавление в меню**: пользователь выполняет документированную команду → запись и значок появляются в пользовательских каталогах → приложение находится в меню по названию и запускается без терминала.
6. **Обновление**: повторная установка → предыдущая версия заменяется → запись в меню и настройки пользователя остаются нетронутыми.
