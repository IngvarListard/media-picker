# Implementation Plan: установка и запуск на любом Linux

**Branch**: `004-distribute-linux` | **Date**: 2026-10-08 | **Spec**: [spec.md](spec.md)

## Summary

Превратить скрипт в устанавливаемый пакет и раздавать его так, чтобы пользователь любого Linux-дистрибутива и десктопа (включая GNOME без Qt) обходился двумя командами: установка и запуск. Графическая библиотека поставляется вместе с приложением — Qt в системе не нужен. Внешний `mpv` по-прежнему ставит сам пользователь, но приложение обязано объяснить это понятным сообщением с командами для распространённых дистрибутивов и не падать. Дополнительно: путь к mpv задаётся в файле настроек, папка загрузок берётся у системы (учитывая локализацию), приложение добавляется в меню отдельной документированной командой.

Ключевое изменение в коде — три точки: `pyproject.toml` (сборочные метаданные, точка входа, зависимость `pyside6-essentials`), чистые функции поиска mpv и сборки команды запуска в `files.py`, и мягкая обработка отсутствия mpv в `media_picker.py`.

## Technical Context

**Language/Version**: Python 3.12+ (существующее требование `requires-python`)  
**Primary Dependencies**: `pyside6-essentials` вместо `pyside6`; новых рантайм-зависимостей нет; сборочная — setuptools  
**Storage**: существующий INI `~/.config/MediaPicker/MediaPicker.ini` плюс один новый строковый ключ `options/mpv_path`; метаданные пакета — в `pyproject.toml`  
**Testing**: существующий unittest; новые чистые проверки в `tests/test_files.py` (поиск mpv, сборка команды), проверка предупреждения в `tests/test_ui.py` с offscreen Qt; ручные сценарии [quickstart.md](quickstart.md)  
**Target Platform**: Linux, любой распространённый десктоп; минимальные системы определяются требованием поставляемой графической библиотеки: Ubuntu 22.04+, Debian 12+, Fedora 35+  
**Project Type**: локальное desktop-приложение  
**Performance Goals**: установка не дольше 3 минут; на работу окна и запуск mpv изменения не влияют  
**Constraints**: без прав root; установка без предварительной установки графических библиотек; mpv — внешняя зависимость; файлы передаются процессу списком аргументов; новых рантайм-зависимостей нет  
**Scale/Scope**: один пользователь, одна машина; правок в двух модулях, один новый тестовый модуль, три упаковочных файла, два workflow, раздел README

| Безопасный запуск | Список аргументов вместо строки оболочки; подсказка об установке mpv содержит только текст, исполнения команд из настроек не появляется. |

## Изменения по шагам

1. **Сборка**: `pyproject.toml` — `[build-system]` setuptools, `[tool.setuptools] py-modules = ["media_picker", "files"]`, `dependencies = ["pyside6-essentials>=6.11.2"]`, `[project.scripts] media-picker = "media_picker:main"`, описание, лицензия, ссылки. `uv sync` пересобирает `uv.lock`.
2. **Поиск mpv и команда запуска**: в `files.py` добавить `find_mpv(explicit, path) -> str | None` (сначала явный существующий путь, затем `shutil.which`) и `build_mpv_command(mpv, video, audio, subtitle, arguments) -> list[str]` с прежним порядком: дорожки → пользовательские ключи → `--` → видео. В `launch()` использовать их; `start_new_session=True` сохранить.
3. **Отсутствие mpv**: если `find_mpv` вернул `None`, показать предупреждение с понятным текстом и командами для Debian/Ubuntu, Fedora, Arch и Flatpak; кнопка «Смотреть» остаётся активной, чтобы после установки mpv не перезапускать приложение. В панели видео при старте выводить ту же мысль коротко, без отдельного окна.
4. **Путь к mpv и папка загрузок**: читать `options/mpv_path` (по умолчанию пусто); при первом запуске брать папку загрузок из `QStandardPaths.writableLocation(DownloadLocation)` с прежним запасным вариантом — домашняя папка.
5. **Значок и меню**: сгенерировать и положить значок 256×256, установить его как значок окна; добавить desktop-запись и метаинфо; в README описать установку в меню двумя командами для текущего пользователя. Аргумент-путь к видео (`Exec=... %F`) в этот этап не входит.
6. **Проверки**: новые проверки чистых функций в `tests/test_files.py`; проверка предупреждения и настройки пути в `tests/test_ui.py`; установка собранного колеса в чистое окружение и запуск из `/tmp`; сессии Wayland и X11.
7. **Раздача**: `ci.yml` — проверки и сборка на Python 3.12 и 3.13; `release.yml` — по тегу `v*` публикация в публичный каталог через доверенную публикацию GitHub и вложения в релиз. До первой публикации README предлагает установку напрямую из репозитория.
8. **README**: раздел «Установка» с двумя командами, таблицей установки mpv, требованием сети и оговоркой о минимальных версиях систем.

## Порядок и границы этапа

Шаги 1–4 и 6 — обязательные для спеки. Шаг 5 закрывает FR-010 (меню) и FR-013 (метаданные значка). Шаг 7 — инфраструктура раздачи; без него установка из репозитория уже работает. Образ приложения без установки, Flatpak, Windows и macOS в этот этап не входят и требуют отдельной спеки.
