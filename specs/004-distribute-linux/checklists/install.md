# Checklist установки и раздачи: Установка и запуск на любом Linux

**Purpose**: Проверить качество требований спеки 004 — полноту, ясность, согласованность и проверяемость правил установки, зависимости от mpv и записи в меню приложений.
**Created**: 2026-10-08
**Feature**: [spec.md](../spec.md), [plan.md](../plan.md), [tasks.md](../tasks.md)

**Note**: Этот чек-лист создан командой `$speckit-checklist` по контексту фичи 004.
**Review Ownership**: Это артефакт проверки качества требований, принадлежащий ревьюеру. Отметка `[x]` ставится только тогда, когда ревьюер убедился, что критерий качества требования выполнен.
**Marker Semantics**: `[x]` означает, что качество требования проверено и признано достаточным. Это не означает, что работа по реализации выполнена.
