# Quickstart: проверка установки и запуска

## Подготовка

Из корня проекта:

```bash
uv sync
uv run python -m unittest discover -s tests -v
```

Для проверок установки понадобится пустой каталог и, по возможности, mpv, убранный из `PATH` (или несуществующий путь в настройках).

## Сценарии

1. **Сборка и установка из колеса**
   ```bash
   uv build
   uv tool install --force ./dist/media_picker-0.1.0-py3-none-any.whl
   cd /tmp && media-picker
   ```
   Ожидание: окно открывается из `/tmp`, настройки пишутся в `~/.config/MediaPicker/MediaPicker.ini`. Проверяет FR-001, FR-003, FR-005, FR-011.

2. **Установка без исходников рядом**
   Собрать колесо, установить, временно переименовать каталог проекта и снова запустить `media-picker` из `/tmp`. Ожидание: приложение работает, ошибок о ненайденных модулях нет. Проверяет FR-005, SC-002.

3. **Отсутствие mpv**
   Указать в настройках `options/mpv_path=/nonexistent`. Запустить приложение, выбрать видео и нажать «Смотреть». Ожидание: понятное сообщение с командами для Debian/Ubuntu, Fedora, Arch и Flatpak; приложение не закрывается, выбор файлов сохраняется. Проверяет FR-006, SC-003.

4. **mpv появился после запуска**
   Вернуть корректный путь к mpv в настройках, не закрывая окно, и снова нажать «Смотреть». Ожидание: видео запускается. Проверяет FR-007.

5. **Нестандартный путь к mpv**
   Сделать в `/tmp/fake-mpv` исполняемый файл-обёртку, которая пишет признак вызова в `/tmp/fake-mpv.log` и завершается, и указать этот путь в `options/mpv_path`. Ожидание: обёртка вызвана, то есть настройка имеет приоритет над `PATH`. Затем указать несуществующий путь, оставив mpv в `PATH`: используется системный mpv. Проверяет FR-008.

6. **Папка загрузок**
   Запустить приложение с чистым INI (временно переместив существующий файл настроек). Ожидание: открыта папка загрузок, определённая системой; при её недоступности — домашняя папка. Проверяет FR-009.

7. **Меню приложений**
   Выполнить документированные команды установки записи и значка, затем найти приложение в меню по названию. Ожидание: запуск из меню без терминала, значок совпадает со значком в списке задач. Проверяет FR-010.

8. **Разные окружения**
   Запустить приложение в сессии X11 (`QT_QPA_PLATFORM=xcb`), в сессии Wayland (`QT_QPA_PLATFORM=wayland`) и с `XDG_CURRENT_DESKTOP=GNOME`. Ожидание: окно открывается во всех случаях, поведение панелей не отличается. Проверяет FR-004, SC-004.

9. **Регрессия прежнего поведения**
   Выбрать видео, внешние дорожки, включить «Поиск во вложенных папках» и «Автовыбор совпадения», нажать «Следующая серия». Ожидание: поведение спек 001–003 без изменений. Проверяет FR-014, FR-015.

10. **Чистое окружение без графической библиотеки**
    Если доступен контейнер (например `docker run --rm -it ubuntu:24.04`), установить приложение и запустить окно в нём. Ожидание: установка проходит без отдельной установки графических библиотек. Проверяет SC-001, SC-004. Если контейнера нет, отметить проверку как невыполненную — не выдавать за успешную.
