## Implementation Strategy

**MVP — US1**: T001–T011. После них приложение уже можно отдать человеку на другом дистрибутиве: установка, запуск из любого каталога, работа без Qt в системе, понятная установка mpv ещё не сделана, но запуск видео с системным mpv уже работает.

**Инкремент 2 — US2**: T012–T016. Закрывает главную боль нового пользователя без mpv.

**Инкремент 3 — US3**: T017–T020. Приятное, но не блокирующее.

**Инфраструктура — T021–T024**: раздача и документация; без них установка из репозитория всё равно работает.

Новых рантайм-зависимостей, модулей-слоёв и тестового фреймворка не вводить. Образ приложения без установки, Flatpak, Windows и macOS в этот этап не входят.
