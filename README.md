# Media Picker

Маленькое окно, которое открывает локальное видео в **mpv** и при желании подключает к нему внешнюю аудиодорожку и субтитры.

## Установка

Есть два пути. Первый работает везде и не зависит от системы. Второй заметно легче, но требует, чтобы Qt уже был в системе и дистрибутив поставлял к нему Python-обвязки.

### Обычный путь: всё внутри

Графическая библиотека приходит внутри приложения, поэтому ставить Qt отдельно не нужно и права root не требуются. Скачивается ~80 МБ, на диске занимает ~230 МБ.

| Способ | Команда |
|---|---|
| Из публичного каталога (заработает после первой публикации) | `uv tool install media-picker` |
| Если уже есть pipx | `pipx install media-picker` |
| Прямо из репозитория, без клонирования | `uv tool install git+https://github.com/IngvarListard/media-picker` |
| Из локальной копии репозитория | `git clone https://github.com/IngvarListard/media-picker && cd media-picker && uv tool install .` |

Запуск — по имени, из любого каталога:

```sh
media-picker
```

Требования: Linux не старше Ubuntu 22.04, Debian 12 или Fedora 35 (нужен glibc 2.34 и новее), Python 3.12+ и однократный доступ к сети при установке. Windows и macOS не поддерживаются.

Qt в системе не нужен — он внутри пакета. Но приложению нужны шесть базовых библиотек, которые есть на любом настольном Linux: glib, OpenGL, fontconfig, xkbcommon и D-Bus. В минимальном окружении (контейнер, серверная установка без графики) их надо доставить — проверено в `ubuntu:24.04`, без них приложение падает с `ImportError: libglib-2.0.so.0`:

```sh
sudo apt install libglib2.0-0 libgl1 libegl1 libfontconfig1 libxkbcommon0 libdbus-1-3
```

### Экономный путь: Qt из системы

Если Qt в системе уже стоит (типичный случай — KDE Plasma) и у дистрибутива есть Python-обвязки Qt, то 80 МБ скачивания можно срезать: берём библиотеку из системы, а ставим только само приложение (~5–10 МБ).

Пример для Ubuntu/Debian — Qt 6.10 уже приходит с Plasma, добавляются только обвязки:

```sh
sudo apt install python3-pyside6.qtcore python3-pyside6.qtwidgets
pipx install --system-site-packages --pip-args="--no-deps" \
  git+https://github.com/IngvarListard/media-picker
```

Оговорки, которые важно знать до того, как вы это выберете:

- Нужен именно **pipx** или обычный `pip`: `uv tool` так не умеет — он всегда делает окружение изолированным ([issue uv](https://github.com/astral-sh/uv/issues/18303)).
- Версия Qt будет из дистрибутива, а не самая свежая: в Ubuntu 26.04 это 6.10.2 против 6.11.2 в пакете приложения.
- На GNOME самих библиотек Qt обычно нет, поэтому к обвязкам добавятся ещё и они — экономия будет меньше, чем на KDE.
- Этот путь **не проверялся** на машине автора (он требует прав root); приложение проверено только обычным путём.
- На других дистрибутивах имя пакета ищите так: `apt search pyside6`, `dnf search pyside6`, `pacman -Ss pyside6`; на Arch это пакет `pyside6`.

### mpv ставится отдельно

Если его нет, приложение не закроется и не промолчит: оно покажет команду установки для вашей системы. После установки mpv нажмите «Смотреть» снова — перезапускать приложение не нужно.

| Система | Команда |
|---|---|
| Debian, Ubuntu | `sudo apt install mpv` |
| Fedora | `sudo dnf install mpv` |
| Arch | `sudo pacman -S mpv` |
| Flatpak | `flatpak install flathub io.mpv.Mpv` |

### Пункт в меню приложений

Необязательно, нужно для запуска мышкой. Команды берутся из склонированного репозитория (папка `packaging/`):

```sh
mkdir -p ~/.local/share/applications ~/.local/share/icons/hicolor/256x256/apps
cp packaging/io.github.IngvarListard.MediaPicker.desktop ~/.local/share/applications/
cp packaging/icons/hicolor/256x256/apps/io.github.IngvarListard.MediaPicker.png \
   ~/.local/share/icons/hicolor/256x256/apps/
update-desktop-database ~/.local/share/applications
```

### Запуск из исходного кода

```sh
uv sync
uv run python media_picker.py
```

Если правите скрипт, переустанавливать приложение не нужно: `uv run` берёт файлы прямо из репозитория. Установленный же через `uv tool` экземпляр держит собственную копию файлов и сам не обновляется.

| Что вы делаете | Нужна ли переустановка |
|---|---|
| Запускаете через `uv run media_picker.py` или `uv run media-picker` | Не нужна — файлы берутся из репозитория |
| Правите скрипт и хотите, чтобы работал установленный `media-picker` | Да: `uv tool install --force .` |
| Один раз поставили `uv tool install --editable .` | Не нужна — правки видны сразу; минус: приложение привязано к папке репозитория |

## Что делает приложение

**Выбор файлов**

- Три колонки: **Видео**, **Аудио**, **Субтитры** — в каждой папки и файлы только разрешённых типов.
- Двойной клик по папке входит в неё, пункт `..` поднимает на уровень выше, одинарный клик выбирает файл.
- В аудио и субтитрах есть пункт «Без внешней дорожки» — он снимает выбор.
- Кнопка «▶ Смотреть» становится активной сразу после выбора видео; внешние дорожки необязательны.
- Под каждым списком показан полный путь выбранного файла.

**Как колонки связаны**

- По умолчанию при выборе видео колонки аудио и субтитров переходят в его папку. Галочка «Панели следуют за видео» отключает эту связь.

**Поиск дорожек**

- В колонках аудио и субтитров можно включить «Поиск во вложенных папках»: тогда видны файлы из папки видео и всех её подпапок, имя которых без расширения совпадает с именем видео или начинается с него и точки (например, `Серия 01.ja.mka` рядом с `Серия 01.mkv`).
- Без этой галочки видны все файлы разрешённых типов в текущей папке, независимо от имени.
- «Автовыбор совпадения» работает в обоих режимах: если подходящий файл ровно один, он выбирается сам; если подходящих несколько, выбор остаётся пустым.

**Следующая серия**

- Кнопка «Следующая серия» ищет дальше по списку единственный файл, в имени которого ровно одно число увеличилось на 1, а остальные части совпали: `S4 - 02 [1080p]` → `S4 - 03 [1080p]`.
- Посторонние файлы пропускаются, но пропущенную серию кнопка не перескакивает. Работает и без внешних дорожек.
- Если выбраны аудио или субтитры, к новой серии подставляются дорожки из тех же подпапок. Это срабатывает и при ручном выборе другого видео, но ручной выбор mpv не запускает — запускает только «Смотреть» или «Следующая серия».
- Если прежнего источника нет или в нём несколько подходящих файлов, новая серия выбирается без запуска: выберите дорожку вручную либо пункт «Без внешней дорожки».

**Ключи mpv**

- Поле «Ключи mpv» добавляет свои параметры к запуску, например `--fullscreen --sub-font="Noto Sans" --volume=80`.
- Текст сохраняется сразу при вводе и восстанавливается после перезапуска; очистка поля тоже сохраняется.
- Значения задавайте через `=`; значения с пробелами берите в одинарные или двойные кавычки; поддерживается экранирование `\`. Команды оболочки, переменные и шаблоны файлов не выполняются.
- Порядок такой: выбранные дорожки → ваши ключи → `--` → видео. Повторы сохраняются: последний `--volume` задаёт громкость, повторные `--audio-file` и `--sub-file` добавляют файлы. Ключи могут переопределить выбор панелей, например `--sid=no` выключает субтитры.
- Незакрытые кавычки, одинокие имена файлов и служебные маркеры `-`, `--`, `--{`, `--}` блокируют запуск с сообщением — текст остаётся, чтобы его исправить. Неизвестные опции и недопустимые значения проверяет сам mpv.

**Что запоминается**

- В `~/.config/MediaPicker/MediaPicker.ini` хранятся папки, выбранная серия, обе галочки, ключи mpv, путь к mpv и разрешённые расширения.
- Если mpv лежит не в `PATH`, его путь можно указать в ключе `options/mpv_path`; пустое значение означает поиск в `PATH`.
- При открытии окна сохранённая серия выделяется снова, но mpv не запускается. Если файл удалён или больше не виден в папке, видео остаётся невыбранным; переход в другую папку сбрасывает сохранённый выбор.
- Первый запуск начинается с `~/Downloads`, а если её нет — с домашней папки.
- Расширения можно поменять в INI, перечислив их через запятую, и перезапустить приложение:

```ini
[extensions]
video=.mkv,.mp4,.webm,.avi
audio=.mka,.mp3,.flac,.aac,.ac3,.eac3,.ogg
subtitle=.ass,.ssa,.srt,.vtt,.sub
```
