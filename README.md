# Media Picker

Окно для запуска любого локального видео через mpv с необязательными внешними аудио и субтитрами.

## Запуск

Нужны Python 3.12+, [uv](https://docs.astral.sh/uv/) и установленный `mpv`.

```sh
uv sync
uv run python media_picker.py
```

В каждой колонке показаны папки и файлы подходящего типа. Двойной клик открывает папку; `..` поднимает на уровень выше. Одинарный клик выбирает файл. В аудио и субтитрах пункт «Без внешней дорожки» снимает выбор. Кнопка «Смотреть» доступна сразу после выбора видео, даже если аудио и субтитры не выбраны.

По умолчанию аудио и субтитры переходят в папку выбранного видео. Галочка «Панели следуют за видео» отключает эту связь. В каждой из двух колонок дорожек можно отдельно включить «Поиск во вложенных папках»: он показывает файлы из папки видео и всех её подпапок, чьи имена без расширения совпадают с видео или содержат суффикс через точку. В режиме обычных папок видны все файлы разрешённых типов независимо от имени.

«Автовыбор совпадения» работает в обоих режимах. Он выбирает дорожку только при одном совпадении; при нескольких оставляет выбор пустым. Под списками всегда показаны полные пути выбранных файлов.

Кнопка «Следующая серия» ищет далее в списке единственный видеофайл, где ровно одно число увеличилось на 1, а остальные части имени совпадают. Например, `S4 - 02 [1080p]` → `S4 - 03 [1080p]`. Посторонние файлы она пропускает, но пропущенную серию не перескакивает. Кнопка работает и без внешних дорожек.

Если аудио или субтитры выбраны, при переходе берутся файлы следующей серии из тех же подпапок. Это работает и при ручном выборе другого видео, но ручной выбор не запускает mpv. В режиме папок колонка открывает папку перенесённой дорожки. Если прежний источник отсутствует или в нём несколько подходящих файлов, новое видео выбирается без запуска: выберите дорожку вручную либо пункт «Без внешней дорожки».

## Настройки

Папки, две общие галочки и разрешённые расширения хранятся в `~/.config/MediaPicker/MediaPicker.ini`. Первый запуск начинается с `~/Downloads`, а если этой папки нет — с домашней папки. Расширения можно изменить в INI, перечислив их через запятую:

```ini
[extensions]
video=.mkv,.mp4,.webm,.avi
audio=.mka,.mp3,.flac,.aac,.ac3,.eac3,.ogg
subtitle=.ass,.ssa,.srt,.vtt,.sub
```

После изменения файла перезапустите приложение.
